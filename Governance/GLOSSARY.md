## Purpose

This glossary defines terms used to manage and document **The STARSET Codex**. It is not the in-universe lore glossary, which will be part of the content itself.

## Project Terms

### Codex

The complete open-source project, including source content, governance, specifications, registries, assets, and generated outputs.

### Governance

Documents that define how the project is managed, reviewed, and changed.

### Specification

An authoritative technical or editorial standard that defines how a project element must be structured.

### Registry

A living authoritative database of allocated identifiers or recognized sources.

### Release

An immutable, versioned distribution of the project or one of its independently publishable components.

### Source of Truth

The single authoritative location for a rule, object, or body of content.

## Documentation Terms

### Archive

An in-universe recovered record presented through the STARSET Society framing device.

### Asset

A non-Markdown project file such as a figure, diagram, map, screenshot, or photograph.

### Canon

Official narrative material evaluated according to [`EDITORIAL_POLICY.md`](EDITORIAL_POLICY.md).

### Canon Confidence

The evidence strength assigned to a claim under [`../Specifications/CANON_CONFIDENCE.md`](../Specifications/CANON_CONFIDENCE.md).

### Citation

A traceable reference connecting a factual claim to one or more registered sources.

### Companion File

A file stored beside a primary Markdown document to provide metadata, source data, manifests, or generated output.

### Diagram

A conceptual visualization such as a flowchart, relationship graph, timeline structure, or technical schematic. Diagrams use `DIG` identifiers.

### Figure

A photograph, screenshot, illustration, artwork, or recreated document. Figures use `FIG` identifiers.

### Manifest

A machine-readable inventory of files belonging to a package or object.

### Map

A geographical, political, site-based, or astronomical representation. Maps use `MAP` identifiers.

### Metadata

Machine-readable descriptive information stored in an external companion YAML file.

### Reconstruction

An evidence-based conclusion not directly stated by an official source.

### Source

A registered work, document, recording, website, demonstration, ARG entry, interview, or other item used as evidence.
